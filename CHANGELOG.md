# Changelog

Все значимые изменения проекта документируются в этом файле.

Формат основан на [Keep a Changelog](https://keepachangelog.com/en/1.1.0/).
Версии проекта следуют [Semantic Versioning](https://semver.org/spec/v2.0.0.html)
в формате `MAJOR.MINOR.PATCH`. На этапе первоначальной разработки используются
версии `0.y.z`; публичный API пока не считается стабильным.

## [Unreleased]

### Added

- Базовый Go-модуль `github.com/p-force/hotel-parser` и точка входа приложения
  с сообщением о запуске.
- Логгер на основе `log/slog` с уровнями сообщений, временем, атрибутами
  и вложенными группами; регрессионный тест группировки атрибутов.
- Многоэтапная Docker-сборка приложения и Docker Compose для локального
  PostgreSQL 17 с постоянным томом данных.
- Пример переменных окружения для подключения к PostgreSQL, таймаута выполнения
  и параметров Bnovo для Arena33.
- Команды Makefile для запуска, сборки, форматирования, статического анализа,
  тестирования и управления зависимостями.
- GitHub Actions CI с проверкой форматирования, `go vet`, тестами с детектором
  гонок и сборкой; версия Go определяется из `go.mod`, зависимости кешируются.
- README с описанием проекта и инструкциями по локальному запуску,
  а также правила исключения служебных файлов для Git и Docker.
- Пакет `internal/config` с моделями конфигурации отеля, источника данных,
  номерного фонда и параметров сбора.
- Загрузка конфигурации из JSON-файла с отклонением неизвестных полей
  и лишних данных после JSON-документа.
- Валидация обязательных полей, часового пояса, HTTPS-адреса источника,
  уникальности категорий и соответствия общего числа номеров сумме категорий.
- Проверка параметров сбора Arena33: два взрослых без детей, один номер,
  положительный горизонт поиска и длительности проживания 1, 2 и 3 ночи.
- Конфигурация `configs/arena33.json` для Arena33 с источником Bnovo,
  19 номерами в трёх категориях и горизонтом поиска 60 дней.
- Тесты загрузки конфигурации Arena33 и валидации её параметров.

### Changed

- Команда `make check` проверяет форматирование без изменения файлов,
  запускает статический анализ, тесты с детектором гонок и сборку.
- CI запускается при push и pull request для веток `dev` и `master`.

### Fixed

- Удалён суффикс `.git` из пути Go-модуля: локальные импорты корректно разрешаются.
- Ранее привязанные атрибуты логгера сохраняют свою группу при добавлении
  вложенных групп.
- В финальный Docker-образ добавлена `tzdata` для загрузки `Europe/Moscow`.
- При ошибке загрузки `Europe/Moscow` логгер использует UTC+3 и выводит
  предупреждение с причиной ошибки.
