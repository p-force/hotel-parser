# Hotel Parser

Сервис мониторинга цен, доступности и занятости номеров отелей.

## Технологии

- Go
- PostgreSQL
- Docker / Docker Compose

## Возможности

Планируемая функциональность:

- Сбор публичных данных отелей через Bnovo, TravelLine и HTML.
- Мониторинг цен и доступности номеров.
- Расчёт занятости по изменению публичных остатков.
- Хранение истории наблюдений в PostgreSQL.
- Формирование Excel-отчётов.

## Локальный запуск

**Требования:** Go и Docker с Docker Compose.

Запуск PostgreSQL:

```bash
docker compose up -d
```

Запуск приложения:

```bash
make run
```

## Команды

```bash
make run      # Запустить приложение
make build    # Собрать бинарный файл
make test     # Запустить тесты
make check    # Форматирование, проверка и тесты
```

## Конфигурация

Пример переменных окружения находится в `.env.example`.

Для локальной настройки:

```bash
cp .env.example .env
```
